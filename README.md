# 🏥 HospitalMS — Hospital Management System

A professional full-stack Hospital Management System built with ASP.NET Core MVC, C#, SQL Server and Entity Framework Core.

## 🚀 Features

### Admin Panel
- 📊 Real-time Dashboard with statistics
- 👤 Patient Management (CRUD)
- 👨‍⚕️ Doctor Management (CRUD)
- 📅 Appointment Management
- 🏥 Department Management
- 👑 User Management with Role-Based Access
- 📧 Automated Email Notifications
- 🔐 Login & Registration System
- 🔑 Forgot Password & Reset

### Patient Portal
- 🏠 Personal Health Dashboard
- 📅 Book Appointments
- 📋 View My Appointments
- 👤 Manage My Profile
- ❌ Cancel Appointments
- 📧 Appointment Confirmation Emails

## 🛠️ Technologies

| Technology | Usage |
|---|---|
| C# / ASP.NET Core MVC | Backend |
| Entity Framework Core | ORM |
| SQL Server | Database |
| Bootstrap 5 | Frontend UI |
| ASP.NET Core Identity | Authentication |
| MailKit / Gmail SMTP | Email Service |
| .NET 10 | Framework |

## 👥 Role System

| Role | Access Level |
|---|---|
| 👑 Admin | Full access — manage everything |
| 👨‍💼 Staff | Add/Edit — no delete |
| 👁️ Viewer | View only |
| 👤 Patient | Personal portal only |
